# 股票趋势筛选工作台 · 分析规则规格

本文档是网页原型与 iOS 工程两端分析引擎的唯一事实来源。任何规则变更必须同步更新本文件与 `data/rules.json`。

## 0. 通用定义

- 日线数组按交易日从旧到新排列，最新一日为 `n-1`。
- `ret(k)` = `(close[n-1] / close[n-1-k] - 1) * 100`。
- `MA(x)` = 最近 x 个交易日收盘价的均值。
- `maUp(x)` = `MA(x)[n-1] > MA(x)[n-6]`（5 日窗口比较，视为“上弯”）。
- `aboveMA(x)` = `close[n-1] > MA(x)`。
- `daysAbove20` = 从最新日向前连续满足 `close > MA20` 的天数。
- `dist20` = `(close / MA20 - 1) * 100`（相对 20 日线的偏离，正数在上方）。
- `distHigh` = `(close / max(close[n-20..n-1]) - 1) * 100`（≤0；-2 表示距 20 日高点 2%）。
- `pullback` = `-distHigh`。
- `volRatio` = 最近 5 日均量 / 最近 20 日均量。
- `breadth20` = 股票池中 `ret(20) > 0` 的标的数量 / 总数。
- `ATR(14)` = 最近 14 个交易日的真实波幅均值；`TR = max(H-L, |H-prevC|, |L-prevC|)`。
- 波动带：`band5 = ATR * sqrt(5) * 1.5`；5 日累计价格变动 `move5 = close[n-1] - close[n-6]`。
  - `move5 > band5` → 波动偏大（上涨过热）
  - `move5 < -band5` → 波动偏大（下跌超跌）
  - 其余 → 波动正常。
- 所有条件缺数据时该项记为“未通过/未知”，并在原因列表标注 `数据不足`；任何核心输入缺失导致无法判定时，结果状态为 `数据不足`。

## 1. 漏斗第一层：大盘环境

主指数为沪深300（`000300.SH`），参考指数为上证指数与创业板指。

### 强

- 沪深300 `ret(20) >= +3%`，且
- 沪深300 `aboveMA20`，且
- 沪深300 `maUp(20)`，且
- 股票池 `breadth20 >= 0.6`。

### 偏弱

- 沪深300 `ret(20) <= -3%`，或
- 沪深300 低于 20 日线 且 `breadth20 <= 0.35`。

### 正常

- 其余情况。

输出：`{ state: 强|正常|偏弱|数据不足, reasons: [逐条依据], implication }`。
`implication` 说明该环境对趋势交易的意义：

- 强：突破与趋势延续的容错较高，个股确认信号更容易成立，但仍需逐票确认。
- 正常：趋势策略需要更严格的量价确认，不追高、等待明确信号。
- 偏弱：突破失败概率较高，优先观察与等待，不把小幅走强当作启动。

## 2. 漏斗第二层：板块强弱

板块口径为申万一级行业（31 个）。每个板块使用行业指数日线与成分股日线。

板块内强势股：`ret(20) >= 8%` 且 `aboveMA20` 且 `ret(5) > 0`。

按优先级判定（命中即停）：

1. **持续强势**：板块 `ret(20) >= 8%` 且 `ret(5) > 0` 且 `aboveMA20` 且 `breadth20 >= 0.5` 且 强势股数 >= 3。
2. **正在加强**：板块 `ret(20) >= 3%` 且（`ret(5) - 前5日涨幅 >= 3 个百分点`）且 `volRatio >= 1.2` 且 `breadth20 >= 0.4`。
3. **开始活跃**：板块 `ret(20) < 3%` 且 `ret(5) >= 3%` 且 `volRatio >= 1.2` 且 强势股数 >= 2。
4. **走弱**：板块 `ret(20) <= -3%`，或（板块低于 20 日线 且 `breadth20 <= 0.35`）。
5. **震荡**：其余。

输出：`{ state, reasons, breadth20, strongCount, strongestMembers: [top3 名称] }`。

## 3. 漏斗第三、四层：个股分类

### 3.1 数据充分性

- 可用交易日 < 60，或最近 5 个交易日成交量全为 0 → `数据不足`。
- 只有不足 15 个可用交易日时，ATR 相关项不输出，并标注【数据不足】。

### 3.2 判定优先级（命中即停）

**排除**（满足任一）：

- `ret(20) <= -5%`
- 低于 20 日线 且 低于 60 日线 且 60 日线未上弯
- `ret(5) <= -10%` 且 `volRatio >= 1.3`（放量下跌）
- 名称含 `ST`

**高位观察**（满足任一）：

- `ret(20) >= 40%`
- `distHigh >= -2%` 且 `dist20 >= 15%`
- `ret(5) >= 15%` 且 `volRatio >= 1.5`（放量急涨）
- `ret(5) < 3%` 且 `volRatio >= 1.5` 且 `ret(20) >= 25%`（放量滞涨）

**回调观察**（全部满足）：

- `pullback >= 8%`
- `ret(5) <= 0`
- 中期未破坏：`maUp(20)` 或 `aboveMA60`

子类型：`volRatio <= 1` → 缩量回调；`volRatio >= 1.5` → 放量回调；其余 → 量能中性。

**启动观察**（全部满足）：

- `ret(20)` 在 [3%, 15%]
- `ret(5) > 0`
- `aboveMA20` 且 `maUp(20)`
- `distHigh >= -5%`
- `volRatio >= 1.2`
- `daysAbove20 <= 10`

**趋势观察**（全部满足）：

- `aboveMA20`
- `dist20 <= 15%` 且 `distHigh >= -10%`
- `ret(5) > -3%`
- `ret(20) > 15%`（且 `ret(20) <= 40%`），或 `daysAbove20 > 10`

**兜底**：

- 若 `ret(20) > 0` 且 `aboveMA20` → `趋势观察`，原因注明“站上 20 日线但动量不足，需观察动量确认”。
- 否则 → `排除`，原因注明“未站上 20 日线或动量不足，暂不满足观察条件”。

输出：`{ type: 启动观察|趋势观察|高位观察|回调观察|排除|数据不足, reasons, subtype?, atr?: {available, flag, band5, move5, atr} }`。

## 4. 个股七步分析

固定顺序：大盘环境 → 板块状态 → 个股中期趋势 → 近期价格行为 → 当前位置 → 下一步观察 → 结论。

### 4.1 中期趋势状态

按优先级：

1. **下跌趋势**：`ret(20) <= -5%` 且 `close < MA20`，或（`close < MA60` 且 60 日线未上弯）。
2. **高位加速**：命中高位观察条件。
3. **涨势走弱**：`close < MA20` 且 20 日线未上弯 且（`close <= MA60` 或 60 日线未上弯或 `pullback > 12%`），且不属于下跌趋势。
4. **调整期**：`close < MA20` 且 `close > MA60` 且 60 日线上弯 且 `pullback <= 12%`。
5. **上升趋势初期**：`aboveMA20` 且 `maUp(20)` 且 `daysAbove20 <= 10`。
6. **升势中**：其余 `aboveMA20` 且 `maUp(20)` 的情况。
7. 兜底：`升势中`，原因注明依据不足。

### 4.2 近期价格行为状态

- **加速上涨**：`ret(5) >= 15%` 或 命中高位观察。
- **启动**：`ret(5) > 0` 且 `ret(20)` 在 [3%, 15%] 且 `volRatio >= 1.2`。
- **回调**：`pullback >= 8%` 且 `ret(5) <= 0`。
- **趋势延续**：其余 `ret(20) > 0` 且 `aboveMA20`。
- **走弱**：其余情况。

### 4.3 当前位置

- **突破附近**：`distHigh >= -3%` 且 `ret(5) > 0` 且 `volRatio >= 1.2`。
- **高位加速后**：命中高位观察条件。
- **上涨后回调**：`pullback >= 8%`；额外输出：是否破坏趋势（`close > MA60` 且 `maUp(20)` → 未破坏；否则 → 已破坏）与量能（`volRatio`）。
- **趋势运行中**：`aboveMA20` 且 `pullback < 8%`。
- 兜底：`趋势运行中`。

### 4.4 下一步观察（按当前类型）

- 启动观察：持续放量能否站稳并突破 20 日高点；回踩 20 日线是否缩量。
- 趋势观察：趋势能否保持；回调是否健康（缩量回踩 20 日线后能否再向上）。
- 回调观察：缩量还是放量；能否重新放量站回 20 日线。
- 高位观察：是否出现滞涨、放量滞涨或跌破 20 日线。
- 排除：能否重新站回关键均线（20 日/60 日），而不是急跌反弹。
- 数据不足：补足 60 个交易日后重新分析。

### 4.5 结论

- `summary`：当前类型一句话。
- `why`：用普通人能理解的语言列出 3～5 条依据，禁止出现“买/卖/目标价/必涨/必跌”。

## 5. 学习模式

每次分析完成后，按当前类型提出 1～3 个问题（见下表）。用户可多选或自由作答；系统用多选对照数据 + 自由文本关键词匹配生成反馈，不判对错。

| 当前类型 | 问题 |
| --- | --- |
| 启动观察 | 你会把它放在哪个观察类型？；这次上涨属于启动还是趋势加速？为什么？；如果接下来回调，你最希望看到价格和成交量出现什么变化？ |
| 趋势观察 | 趋势延续最需要盯住哪个信号？；如果回调，你希望看到缩量还是放量？为什么？；什么情况出现会让你重新判断它不是趋势观察？ |
| 高位观察 | 什么信号出现会让你警惕？；放量滞涨说明什么？；如果它开始回调，你想先看哪个指标？ |
| 回调观察 | 回调是缩量还是放量？你认为哪种更健康？；回调是否破坏了上升趋势？你用什么判断？；如果重新向上突破，你想看到什么确认？ |
| 排除 | 你觉得它被排除的主要原因是什么？；什么条件变化后它值得重新进入观察？ |
| 数据不足 | 缺少哪些数据会让你无法判断？ |

反馈固定输出三段：

- 【你的判断】：先肯定用户做对的地方与识别出的因素（依据多选命中或关键词命中）。
- 【容易忽略的地方】：列出数据中存在但用户未提及的因素。
- 【进一步思考】：解释为什么这些因素重要，引导理解“市场→板块→个股趋势→涨跌程度→当前位置→下一步”框架。

## 6. 「我为什么看好」结构化复盘

表单字段：理由类型（技术形态 / 消息催化 / 基本面 / 资金流向 / 情绪博弈，可多选）、时间预期（短线 5 日 / 波段 20 日 / 中线 60 日）、自由文本。

系统输出对照表：

| 理由类型 | 系统依据（数据） | 对照结论 |
| --- | --- | --- |
| 技术形态 | 当前分类状态、位置、量价数据 | 一致 / 冲突 / 未覆盖 |
| 消息催化 | 快照无新闻数据 → 标注【数据不足，不许编造】 | 未覆盖 |
| 基本面 | 快照无财务数据 → 标注【数据不足】 | 未覆盖 |
| 资金流向 | 快照无资金流数据 → 标注【数据不足】 | 未覆盖 |
| 情绪博弈 | 板块赚钱效应、量比佐证 | 一致 / 冲突 / 未覆盖 |

时间预期对照对应窗口涨跌幅（短线→5 日、波段→20 日、中线→60 日）。最后给一句追问，不否定用户判断。

## 7. 输出红线

- 任何界面不出现“买入、卖出、目标价、必涨、必跌”等交易信号。
- 每个结论必须带逐条判断依据。
- 数据不足时明确显示【数据不足，不许编造】。
- 不预测确定的未来走势。
