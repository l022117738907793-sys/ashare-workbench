## 一、这个工具是干什么的

它做一件事：**把 A 股几千只股票，按「趋势」筛成几类，并告诉你每一类是怎么判断出来的。**

它不是荐股软件，不会告诉你买什么。它给的是**结构化的观察结论 + 完整判断依据**，怎么用由你自己决定。

### 它的核心是四层漏斗

```
① 大盘环境      现在整体市场适不适合做趋势？
      ↓
② 板块强弱      哪些行业在走强、哪些在走弱？
      ↓
③ 个股分类      这只股票属于哪一类？
      ↓
④ 个股分析      七个步骤拆开看，每一步都有依据
```

一层层收窄。大盘不好的时候，后面几层的结论要打折看。

## 二、五个页面

底部五个标签：

### 1. 筛选 —— 主页面，看漏斗

从上到下三块：

| 区块 | 看什么 |
|---|---|
| **① 大盘环境** | 沪深300 的状态，加股票池的「赚钱效应」（多少股票在涨） |
| **② 板块强弱** | 31 个申万一级行业，按强弱排序。点一个可以筛选 |
| **③ 个股分类** | 分成六类，点击任意个股进入详细分析 |

**六种分类的含义**：

| 分类 | 意思 |
|---|---|
| 启动观察 | 刚放量启动，站上 20 日线 |
| 趋势观察 | 已经在趋势里 |
| 回调观察 | 涨过之后在回调，看回调是否健康 |
| 高位观察 | 涨太多了，注意滞涨风险 |
| 排除 | 走势走坏，暂不关注 |
| 数据不足 | 数据不够，不做判断 |

> 每个分类下面都有一行行小字，那是**判断依据**。看不懂结论的时候，就看依据。

### 2. 个股分析 —— 点开一只股票后看这里

**七步分析**，固定顺序：

① 大盘环境 → ② 板块状态 → ③ 个股中期趋势 → ④ 近期价格行为 → ⑤ 当前位置 → ⑥ 下一步观察 → ⑦ 结论

顶部还有一张**交易信号卡**（下面单独说）。

页面下方还有两个互动模块：
- **学习模式**：系统按当前分类给你出 1-3 道题，你答，它给反馈（**不判对错**，只做对照）
- **我为什么看好**：你写下自己的理由，系统拿数据跟你对一遍，看哪些理由有数据支持、哪些没有

### 3. 模拟盘 —— 虚拟资金练手

给 100 万虚拟资金，按 A 股真实规则撮合。**详细规则见下方第四节。**

### 4. 历史 —— 你分析过什么

自动记录你分析过的股票和学习记录，存在**你自己的浏览器里**，不会上传。

### 5. 设置

可以调阈值、改刷新间隔、清空本地数据。**新手不用动。**

## 三、怎么读「判断依据」

这是整个工具最重要的东西。每个结论下面都有一行行：

```
沪深300 近20日涨幅    -2.31    阈值 ≥ 3%      未通过
价格站上20日线         0       阈值 是        未通过
股票池上涨家数占比      31.5    阈值 ≥ 60%     未通过
```

读法：**左边是实际值，中间是要求，右边是通过还是没通过。**

结论不是拍脑袋来的，是这些条件算出来的。**你想反驳结论，就看哪一条判断依据你不认同。**

### 关于【数据不足，不许编造】

如果某只股票可用交易日不够（少于 60 天），或者长期停牌，系统会明确显示**「数据不足」**并列出缺什么。

**它不会猜。** 缺数据就是缺数据，不会用 0 或者推测值顶上去。看到这四个字，说明这只股票现在没法判断，不是系统坏了。

## 四、模拟盘怎么玩

### 规则和真实 A 股一致

| 规则 | 说明 |
|---|---|
| **T+1** | 今天买的，明天才能卖。当天买入的部分显示为「不可卖」 |
| **涨跌停** | 涨停买不进、跌停卖不出（主板 ±10%、创业板科创板 ±20%、ST ±5%） |
| **手续费** | 佣金万 2.5（最低 5 元）+ 印花税千 1（仅卖出）+ 过户费万 0.1（双向） |
| **滑点** | 买入价上浮 0.1%、卖出价下浮 0.1%，模拟冲击成本 |
| **一手 100 股** | 买卖需为 100 股整数倍；卖出可不足一手但要一次清仓 |
| **停牌 / 没行情** | 直接拒绝下单，**不猜价格** |

界面里点**「规则说明」**有每一条的详细解释（为什么有这条、对收益有什么影响）。

### 成绩怎么算

**只看绝对收益没意义** —— 牛市里随便买都赚钱。所以成绩是：

> **超额收益 = 你的收益 − 同期沪深300 收益**

同时看**最大回撤**（中途最多亏多少）和**胜率**。收益高但回撤一半的策略，多数人拿不住。

### 一句提醒

模拟盘用的是真实行情、真实规则，但**是虚拟资金**。它不构成任何投资建议。

## 五、交易信号（重要，务必看完）

个股分析页顶部那张卡片会给出**买入 / 增持 / 持有 / 减持 / 卖出 / 观望**，还有三个参考价位。

### 但这个信号**没有证据支持它有效**

我们用它自己的历史数据做了回测（580 个交易日），结论是：

| 检验 | 结果 |
|---|---|
| 看多信号 vs 看空信号的前瞻收益差 | 只有 **+0.16 ~ 0.27 个百分点** |
| 统计检验（三种方法） | **全部跨越 0**，即与随机无法区分 |
| 28~115 个独立检验窗口 | 为负的比例接近抛硬币 |

**说白了：这个信号的准确度和抛硬币差不多。**

界面上的卡片里也写着这句话。留着它是因为它展示了完整的判断逻辑，**当观察框架可以，当交易依据不行**。

三个参考价位（买入价 = 20 日线，止损 = 买入价 − 2 倍 ATR，目标 = 现价 + 3 倍 ATR）是**技术测算，不是收益承诺**。

## 六、常见问题

**Q：数据是实时的吗？**
A：分两层。**历史日线**每个工作日 18:30 自动更新一次；**盘中价格**是实时的（交易时段每 3-5 秒刷新）。两个数字来源不同，页面上都会标注。

**Q：为什么收盘后价格不动了？**
A：不在交易时段就不请求行情，这是省流量也是尊重接口。页面顶部会显示当前状态（交易中 / 已收盘 / 午间休市）。

**Q：提示「行情降级」是什么意思？**
A：数据源按 腾讯 → 东方财富 → 本地快照 的顺序自动切换。降级时页面会**明确告诉你实际用的是哪个源**，不会偷偷换掉。

**Q：手机上怎么用得舒服点？**
A：Safari 点分享 → 添加到主屏幕；安卓 Chrome 点菜单 → 添加到主屏幕。

**Q：我的操作记录会上传吗？**
A：不会。历史记录、模拟盘账户、设置全部存在**你自己浏览器的本地存储**里。换设备或清浏览器数据就没了。设置页有「清空本地数据」。

**Q：股票池为什么只有 92 只？**
A：这是演示池 —— 申万 31 个一级行业，每个行业取市值前几只代表股。不是全市场 5000 多只，因为逐只拉历史数据会被行情接口限流。

**Q：为什么我的股票搜不到？**
A：同上，只有池子里的 92 只能分析。可以在设置里调整行业代表股数量后重新生成数据（见下）。

## 七、给维护者：怎么改

### 更新数据

数据是 **GitHub Actions 自动更新的** —— 每个工作日北京时间 18:30 抓当日数据并提交，提交后自动重新部署。**通常不用手动管。**

想手动更新：仓库 `Actions` → `Update Daily Snapshot` → `Run workflow`。

### 改判断阈值

编辑 `data/rules.json`，提交即可生效。也可以在**设置页里临时覆盖**几个常用阈值（只影响你自己的浏览器）。

改之前建议先看 `docs/analysis-rules.md` —— 那是规则的唯一事实来源。

### 拉更长的历史（做回测用）

```bash
python3 packages/data/scripts/fetch_snapshot.py --days 650
npx vite-node scripts/backtest.ts
```

默认快照只有 120 天，回测样本不够。拉长到 650 天后可回放约 580 个交易日。

> ⚠️ 这一步**很慢**（约 10 分钟）。瓶颈是 akshare 逐个拉 31 个申万行业指数，每个约 13 秒。
> 这是正常现象，不是卡死 —— 判断进度请看日志，**不要看 `ps` 的 CPU 占用**，那是生命周期平均值，等待网络时会接近 0。

### 本地开发

```bash
npm install
npm test                    # 218 个测试
npm run dev --workspace @aw/web
npm run build --workspace @aw/web
```

## 八、这个工具不做什么

明确说清楚，免得误会：

- ❌ **不给买卖建议**（信号已证明无效，见第五节）
- ❌ **不预测涨跌**
- ❌ **数据不足时不编造**
- ❌ **不做实盘交易**，不接任何券商接口
- ❌ **没有基本面数据**（财务、估值、资金流都没有），纯技术面
