# 给 ChatGPT 的独立审查提示词

**用法**：新建一个 ChatGPT 对话，把下面 `---` 之间的内容整段粘贴进去，
并**附加两个文件**（拖进对话框即可）：

- `scripts/backtest.ts`
- `README.md`（其中「回放压测」一节是重点）

> 为什么要附文件：ChatGPT 桌面端读不到你本地磁盘（不像 Codex CLI 能直接读工作目录），
> 所以必须手动附加，否则它只能靠下面的描述来回答，独立性会打折。

---

你是一位量化研究方法论审稿人。请对下面这个回测做**对抗性审查**，目标是找出它错在哪里，
而不是确认它对。附件里是回测脚本与项目 README（重点看「回放压测」一节）。

## 场景

一个 A 股趋势筛选工具，把股票分类映射成买卖信号：
启动观察/回调观察→买入、趋势观察→增持、高位观察→减持、排除→卖出、数据不足→观望。

回测方式：逐日 walk-forward。对每个历史交易日 D，**只用 [0, D] 的数据**重算信号，
再看 D 之后 5/10/20 日的实际收益。

数据：单一快照，含 120 个交易日 × 92 只个股的日线，可回放其中 60 天。

## 已得到的三轮（互相矛盾的）结果

**第一轮·重叠样本看均值**：看多组的前瞻收益低于看空组，且强度越高越差
（+10 日：买入 −3.37%、卖出 +1.64%；强度≥80 为 −3.49%、强度<40 为 +1.64%）。

**第二轮·加统计校正**：
- 分块自助法（块长 10 日 × 2000 次重采样）：+10 日价差 95% 区间 [−4.30, −0.32]、+20 日 [−5.58, −0.39]，均不跨 0
- 逐日方向检验 + `t/√h` 重叠校正：未校正 t 为 −3.32 / −4.96 / −4.84，**校正后为 −1.49 / −1.57 / −1.08，全部不显著**

**第三轮·稀疏非重叠检验**（每隔 h 日取一个起点，让前瞻窗口互不重叠）：
- +5 日：11 个独立起点，其中 **6/11** 价差为负
- +10 日：5 个起点，其中 **2/5** 为负
- +20 日：2 个起点（样本量无意义）

**数据质量**：收盘价序列 null 占比 0.0091%（1/11040），缺失删样率 0.000%。
样本量从 5520 降到 3680 主要是**边界截断**（起点靠近末尾时 d+k 越界），非停牌删样。

## 请回答

1. **三轮结论矛盾，应以哪一轮为准？** 稀疏非重叠检验只有 5~11 个起点，
   它推翻前两轮（数百到数千样本）是否合理？还是说它本身样本太少同样不可信？
   如果三者都不可信，正确的做法是什么？

2. **`t/√h` 这个校正**在"日频采样、h 日前瞻、随机游走"假设下是否恰当？
   若实际收益存在动量或反转（即自相关不为零），它会偏乐观还是偏保守？
   在这个场景下应该用什么替代（HAC/Newey-West？按日期聚类？block bootstrap 的块长怎么选）？

3. **最严重的偏差是什么？** 我认为是股票池按**当前**市值权重选取，
   导致前视/生存偏差；但也有人认为对"看多 vs 看空"的**价差**而言，
   池子层面的偏差会被差分掉（两组来自同一个池子），因此影响有限。
   你同意哪一方？为什么？

4. **在只有 60 个交易日、20 日窗口只有约 3 个独立观测的前提下**，
   有没有任何合法的统计手段能给出有意义的结论？
   如果没有，一份诚实的报告应该怎么写？

5. **最小改进**：按性价比排序给最多 4 条（不增加数据的前提下）。

最后给一个明确判断：**基于现有证据，能否给出关于该信号质量的任何结论？**
回答「能（说明方向与置信度）/ 不能」，并说明理由。

请用中文，控制在 900 字以内。直接给结论与依据，不要复述我给的描述。
