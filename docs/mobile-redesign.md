# 股市练习场：手机优先的前端重设计

完成日期：2026-10-06。基于原仓库 main 提交 `bd94900b0edab75470b98caa115f7a318eb7dbbc`。
本次已实现前端代码，并完成本地验证；GitHub Pages 线上网站尚未发布此版本。

## 设计目标

打开应用先进入游戏。新手能辨认传奇、实时和随机三种玩法；进入一局后，容易找到选股、下单、待成交委托和时间推进。手机是主要使用场景，桌面采用相同视觉语言。

## 已实现的界面

- 统一深色背景、暖橙色主操作、卡片层级与字形；A 股涨跌继续红涨绿跌。
- 默认首页为游戏大厅。手机取消装饰行情插画，缩短介绍；三种模式采用可点击的竖向卡片。桌面为三列。
- 手机固定底部导航，大厅的进入按钮固定在底部导航上方；桌面顶部导航。数据来源详情按需展开；切换视图与开局后回到顶部。
- 传奇选关：手机横向章节列表、滑动提示、当前章节简报、虚拟本金及进入按钮。保留真实日期与各关可用状态。
- 历史盘：暂停／走一天／快进、账户、选股、下单与待成交委托优先。手机先显示操作区，再显示图表和资讯。主要操作至少44px点击高度；数字与文本输入避免 iOS 自动放大。
- 实时盘：账户核心四项指标优先，基准与交易统计折叠；下单和持仓靠前，资讯与日志折叠。候选股票列表在卡片内滚动。
- 历史价格／成交量图：只取当前交易日及以前的数据，未来行情和未来成交不会进入 SVG 或悬浮信息；随机模式隐藏真实日期。空数据保持缺失，异常数值不会填造。
- 翡翠教学助手复用已有六组表情与眨眼素材，增加轻微呼吸动画；台词随大厅、选关、历史盘、实时盘和存档状态变化。支持减少动画的系统设置。
- 新手指南先展示读信息、挂单等次日、复盘三步，原有进阶说明仍可展开。

## 文件入口

`apps/web/src/redesign.css`：共享视觉系统与手机覆盖样式。

`App.tsx`、`main.tsx`、`index.html`：默认游戏入口、导航、页面标题与布局。

`GameView.tsx` / `game-view.css`：大厅与实时盘。

`LevelPicker.tsx` / `level-picker.css`：传奇选关。

`ReplayView.tsx` / `replay-view.css` / `ReplayChart.tsx`：历史游戏界面及可见行情图。

`GameCompanion.tsx` / `AppIcon.tsx`：翡翠操作帮助与图标。

`GuideView.tsx`：游戏入门指南。

`apps/web/device-preview.html`：本地手机尺寸预览页，可切换360、390、430px；开发预览使用，不作为Vite正式构建入口。

## 接入与约束

交易引擎、行情接口与本地存档格式继续使用原项目代码。实时账户与历史账户各自保存。已有历史存档时先继续原局，禁用创建另一局的历史入口，以免覆盖。

快进仍为1.5秒／交易日，播放时允许挂单；次日开盘撮合、T+1、涨跌停、滑点、费用与撤单调用原有接口。阶段结算只显示当前成绩，允许继续推进。

翡翠的自由提问复用原有 AskBox 与设置中的 AI 接口。配置接口后可调用；未配置时显示原有提示。本次未创建服务端或写入API密钥。历史模式的帮助上下文为操作规则，未把未来行情交给AI。

Vite继续使用相对资源路径，兼容仓库现有GitHub Pages部署流程。上线前合入源代码并按原部署工作流构建即可，避免把本地数据副本当作新的权威数据源。

## 本地运行

在项目根目录运行：

```sh
npm ci
node packages/data/scripts/sync_web_data.mjs --keep 1 --trim-days 120
npm run dev --workspace @aw/web -- --port 5180
```

应用地址为 `http://127.0.0.1:5180/`；手机尺寸预览为 `http://127.0.0.1:5180/device-preview.html`。
