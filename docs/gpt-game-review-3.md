# 第三方评审意见（第三轮）

来源：用户转来的 GPT 体验报告（截图 OCR）。体验者实际走了一遍：实时盘买入中国平安并尝试当天卖出、
随机盘完成买入 / 快进挂单 / 卖出 / 结算，另进了「春节之后」这一关传奇模式。
报告原话：「交易流程已经能跑通，最需要补的是行情一致性和决策、复盘的信息」，建议「按这个顺序改」。

原文照录（只做了断行整理，未改措辞）：

1. **先修成绩基准。** 实时盘刚开局、没有交易，就显示沪深300 −5.45%、超额收益 +5.45%；更新行情后又变成
   「—」。账户和指数应从同一时刻开始计算，数据不足时明确提示，避免玩家一进来就「获胜」。
2. **成交前先确认行情是否新鲜。** 中国平安下单前显示本地快照 52.50 元，成交价 52.55 元；买入后行情才更新到
   53.29 元，账户立刻出现浮盈。建议成交前刷新报价，并让撮合、估值使用一致行情时间。否则玩家可能把数据
   更新当成自己的盈利能力。
3. **历史盘必须有可判断的信息。** 随机盘选股后只看到当日收盘价，没有历史走势图、成交量或当天新闻。
   传奇盘有开局简报，但推进日期后没有看到持续更新的信息。优先补上「截至当前模拟日的走势 + 当天信息」，
   否则新手还是在猜涨跌。
4. **让复盘解释决策。** 我随机盘赚了 287.26 元，结算展示收益、回撤、胜率，但没有解释这笔交易的过程。
   可以下单时记录一句买入理由，结束后对照买卖点、持有期间走势和当时信息。AI 老师再追问「判断依据是什么、
   哪里需要修正」，学习价值会明显提高。
5. **把交易区和快进控制放到更容易操作的位置。** 当前窄屏里实时盘新闻列表很长，传奇盘简报也占一大块，
   下单区需要往下找。建议简报可折叠，固定暂停按钮，并增加「1/4、1/2、全仓」快捷数量。快进期间的成交用
   醒目提示反馈，才能形成您想要的紧张感。
6. **补清楚结算和模式状态。** 实时盘点击结算只提示「净值点不足」，没有说明还差多少；随机盘第 7 天也能
   「结算本局」，之后仍可继续。建议区分「查看阶段成绩」和「结束本局」，显示结算条件。另外，历史关卡顶部
   仍显示 2026 年的快照，切到筛选页也是今日信号，容易混淆，应明确标出当前信息属于哪个时间。

值得保留的地方：T+1 拦截清楚，历史盘次日开盘成交的说明好懂，快进中挂单和暂停也确实可用。

本轮未验证：这次是在页面显示「已收盘」时体验的，盘中实时撮合、涨跌停和停牌边界还没有验证。
